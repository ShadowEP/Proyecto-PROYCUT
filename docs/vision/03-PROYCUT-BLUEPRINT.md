El Plano Maestro de ProyCut
"Una idea entra. Un proyecto rentable sale."
Ese es el flujo completo de ProyCut.
Todo lo demás son herramientas para hacerlo posible.

1. El propósito del sistema
ProyCut existe para acompañar al usuario durante todo el ciclo de vida de un proyecto.
No solamente para cotizarlo.
No solamente para optimizar cortes.
No solamente para fabricar.
Sino para conectar todas las etapas del proceso en una sola plataforma.
Desde la primera idea hasta la entrega del proyecto terminado.

4. El corazón de ProyCut
No es el optimizador.
No es el 3D.
No es la IA.
El corazón es el Proyecto.
Todo nace y termina en un proyecto.
Por eso, prácticamente todos los módulos estarán relacionados con él.

6. La gran regla de ProyCut
Todo en ProyCut debe girar alrededor del Proyecto.
No alrededor de un cliente.
No alrededor de una cotización.
No alrededor de un tablero.
No alrededor de un reporte.
Todo existe para ayudar a que un proyecto llegue desde una idea hasta una fabricación rentable.
Si un módulo no aporta valor al proyecto, probablemente no pertenece al sistema.
